# SAFE B-MOD — เว็บลงทะเบียนเข้าร่วมโครงการ (Production, พร้อมระบบ Admin + Excel Export)

## ⚠️ ต้องทำก่อนอื่น — เรื่องความปลอดภัย

โค้ดเวอร์ชันก่อนหน้าที่ส่งมามี **Gmail App Password จริงฝังอยู่ในไฟล์ `server.js`**
ถ้ายังไม่ได้เพิกถอนรหัสนั้น ให้ทำตามนี้ทันที **ก่อน** จะ push โค้ดขึ้น GitHub:

1. ไปที่ https://myaccount.google.com/apppasswords
2. หา App Password ตัวที่เคยสร้างไว้ (ที่ขึ้นต้นด้วยอะไรทำนอง `tccc kxlw ...`) แล้วกด **ลบ/เพิกถอน**
3. สร้างรหัสใหม่ แล้วนำไปใส่เป็น environment variable `GMAIL_APP_PASSWORD` บน Render เท่านั้น **ห้ามใส่ในไฟล์โค้ดอีก**

โค้ดเวอร์ชันนี้แก้ให้ดึงรหัสจาก environment variable แล้ว ไม่มีรหัสผ่านฝังอยู่ในซอร์สโค้ดอีกต่อไป

## สิ่งที่แก้ไขจากโค้ดที่ส่งมา

1. **ข้อมูลไม่หายเมื่อเซิร์ฟเวอร์รีสตาร์ท** — เดิมเก็บข้อมูลไว้ใน `let registrations = []` (ตัวแปรในหน่วยความจำ) ซึ่งจะหายทันทีที่ Render restart/deploy ใหม่ (เกิดขึ้นได้บ่อยบนแผนฟรี) เปลี่ยนมาใช้ **PostgreSQL** แทน เพื่อให้ข้อมูลอยู่ถาวรจริง
2. **หน้า Admin (`/admin`) และ API ของแอดมินไม่มีการล็อกอินเลย** — เดิมใครก็เข้า `/admin` ดู/ลบข้อมูลผู้ลงทะเบียนทุกคนได้ทันที เพิ่ม **HTTP Basic Auth** (username/password ผ่าน environment variable `ADMIN_USER` / `ADMIN_PASS`) ครอบทั้ง `/admin`, `/api/admin/registrations`, `/api/admin/export-excel` — ถ้าไม่ตั้งค่าไว้ ระบบจะล็อกไว้เป็นค่าเริ่มต้น (fail closed) ไม่ใช่เปิดโล่งเป็นค่าเริ่มต้น
3. **ปุ่ม "Export Excel" เดิมลิงก์ไปที่ endpoint ที่ไม่มีอยู่จริง** (`/api/admin/export-excel` ไม่เคยถูกสร้างใน server.js) เพิ่ม endpoint นี้จริง โดยใช้ `exceljs` ที่ติดตั้งไว้แล้วแต่ไม่เคยถูกใช้งาน
4. **หน้า "ตรวจสอบรายชื่อ" (`goCheckStatus`) เรียก API ที่ไม่มีอยู่จริง** (`/api/registrations/public`) เพิ่ม endpoint นี้ — **แต่จำกัดข้อมูลที่ส่งออกเฉพาะ ชื่อ-นามสกุล ตำแหน่ง สังกัด เท่านั้น ไม่ส่งเบอร์โทร/อีเมล/ที่อยู่ออกไปให้สาธารณะเห็น** และเพิ่ม environment variable `ENABLE_PUBLIC_LIST=false` ให้ปิดฟีเจอร์นี้ได้ทันทีโดยไม่ต้องแก้โค้ด ถ้าภายหลังพิจารณาแล้วไม่อยากเปิดให้สาธารณะค้นหาได้
5. **ฟอร์มลงทะเบียนมีสองระบบซ้อนกันและขัดแย้งกัน** — ไฟล์ `js/script.js` มีฟังก์ชัน `submitForm()` ที่เขียนไว้ดีอยู่แล้ว (เติมกล่องสรุปข้อมูลให้ครบ) แต่ `<form>` ใน `index.html` ไม่ได้เรียกใช้ฟังก์ชันนี้เลย ส่วน `<script>` ก้อนที่แปะไว้ท้ายไฟล์ HTML ต่างหากคือตัวที่ทำงานจริง — แต่เวอร์ชันนั้นไม่เติมกล่องสรุปข้อมูลให้ ผลคือหลังลงทะเบียนสำเร็จหน้าจอจะว่างเปล่า **แก้โดยลบ `<script>` ซ้ำซ้อนออก แล้วผูก `<form>` เข้ากับ `submitForm()` ใน script.js ให้ถูกต้อง**
6. **อีเมลยืนยันทำให้การลงทะเบียนล้มเหลวไปด้วยถ้าส่งอีเมลไม่สำเร็จ** — เดิมโค้ด insert ข้อมูลกับส่งอีเมลอยู่ใน try/catch เดียวกัน ถ้าอีเมลส่งไม่ผ่าน (เช่น รหัสผิด/เน็ตมีปัญหา) ทั้งที่ข้อมูลถูกบันทึกแล้ว ระบบจะแจ้งผู้ใช้ว่า "ผิดพลาด" ทำให้เข้าใจผิดว่าลงทะเบียนไม่สำเร็จ **แก้ให้ตอบกลับผู้ใช้ทันทีว่าสำเร็จหลังบันทึกข้อมูลเสร็จ แล้วค่อยส่งอีเมลแยกต่างหาก การส่งอีเมลพลาดจะไม่กระทบผลการลงทะเบียนอีกต่อไป**
7. เพิ่ม server-side validation (ช่องบังคับ, รูปแบบเบอร์โทร/อีเมล) ที่ `/api/register` ไม่ให้พึ่งพา validation ฝั่ง frontend อย่างเดียว
8. เติมปุ่ม "อ่านเพิ่มเติม" ที่หายไปในส่วนหลักการและเหตุผล (เนื้อหาย่อหน้าที่ 2 เคยถูกซ่อนถาวร)
9. แก้ layout ของ Hero ที่เพี้ยน — CSS เดิมยังใช้ `display:grid; grid-template-columns:1.15fr 0.85fr` (ออกแบบไว้สำหรับ 2 คอลัมน์คู่กับภาพประกอบ) แต่ HTML ปัจจุบันเหลือแค่คอลัมน์เดียว ทำให้เนื้อหาเบียดชิดซ้ายไม่เต็มจอ ปรับเป็น layout คอลัมน์เดียวจัดกึ่งกลางให้ตรงกับ CSS ที่คุณเพิ่มเข้ามาเอง (`.hero h1{max-width:650px;margin:0 auto}`)

ทดสอบแล้วด้วย html-validate + รันเซิร์ฟเวอร์จริงยิง endpoint ทุกจุด **ผ่านหมด**

## วิธี Deploy บน Render

1. Push โฟลเดอร์นี้ขึ้น GitHub (**ตรวจสอบว่าไม่มีไฟล์ `.env` ติดไปด้วย** — `.gitignore` กันไว้ให้แล้ว)
2. Render Dashboard → New → **Blueprint** → เลือก repo นี้ → Apply
3. Render จะสร้าง Web Service + PostgreSQL ให้อัตโนมัติ และตั้ง `DATABASE_URL`, `ADMIN_PASS` ให้เอง
4. เข้าไปที่แท็บ **Environment** ของ Web Service แล้วเพิ่มเอง (ไม่ auto-fill เพราะเป็นข้อมูลส่วนตัวของคุณ):
   - `ADMIN_USER` — ชื่อผู้ใช้สำหรับเข้า `/admin`
   - `GMAIL_USER` / `GMAIL_APP_PASSWORD` — ถ้าต้องการส่งอีเมลยืนยัน (ไม่ตั้งก็ได้ ระบบจะข้ามการส่งอีเมลไปเฉยๆ)

## การใช้งานหลัง Deploy

- หน้าเว็บลงทะเบียน: `https://<ชื่อเว็บของคุณ>.onrender.com/`
- หน้าแอดมิน (ต้องล็อกอิน): `https://<ชื่อเว็บของคุณ>.onrender.com/admin`
- ปุ่ม "Export Excel" ในหน้าแอดมิน ดาวน์โหลดไฟล์ .xlsx ได้ทันที

## หมายเหตุเรื่อง Render free tier

- Web Service แผนฟรีจะ "หลับ" เมื่อไม่มีคนเข้าเว็บสักพัก (ตื่นครั้งแรกช้าราว 30-50 วินาที)
- PostgreSQL แผนฟรีของ Render จะถูกลบข้อมูลอัตโนมัติหลังผ่านไป 90 วัน — ถ้าโครงการมีระยะเวลานานกว่านั้น ควรอัปเกรดฐานข้อมูล หรือ export Excel สำรองเป็นระยะ
